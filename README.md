# 多语种铁路检修记录与设备限制联动

本项目整理铁路检修控制室从承包商交班文本、调度通告和现场复核记录接收故障描述。设备昵称与线路正式编号经常混用，临时限速的解除条件也可能晚于维修完成记录；把文本分类结果直接当成设备恢复会让调度人员基于过时限制安排运行。

演练资料位于 `data/rail.json`，内容为合成记录，保留不同来源的原始表述和修订关系。项目环境使用 Python 3.11 标准库。

当前资料检查入口为 `python3 -m unittest discover -s tests -v`。检查仅确认 JSON 文件可以读取、记录字段完整且每条原文存在，不会生成业务判断。尚无面向使用者的业务命令。
